\subsubsection{Shared Bell Pair and Initial Three-Qubit State}\label{sec:shared-bell-pair-and-initial-three-qubit-state}

In this section, we will prepare the starting point for the quantum teleportation protocol:
\begin{itemize}
    \item Alice will have the unknown qubit.
    \item Alice and Bob will share an entangled Bell pair.
    \item The entire three-qubit system will be written as one combined state.
\end{itemize}

\highspace
\begin{flushleft}
    \textcolor{Green3}{\faIcon{hourglass-start} \textbf{Before anything happens}}
\end{flushleft}
At the beginning, \textbf{there are three qubits}.
\begin{equation*}
    \text{Alice } = \underbrace{q_{\psi}}_{?} \quad \underbrace{q_A}_{0} \qquad \text{Bob } = \underbrace{q_B}_{0} 
\end{equation*}
The first qubit is the unknown state:
\begin{equation*}
    \ket{\psi} = \alpha \ket{0} + \beta \ket{1}
\end{equation*}
The other two are initially just \ket{00}. Alice owns \textbf{two qubits} and Bob owns \textbf{one qubit}.

\highspace
\begin{flushleft}
    \textcolor{Green3}{\faIcon{link} \textbf{Alice and Bob create an entangled pair}}
\end{flushleft}
Now Alice and Bob prepare the Bell state (\autopageref{eq:bell-states}):
\begin{equation}\label{eq:bell-pair-quantum-teleportation}
    \ket{\Phi^+} = \frac{1}{\sqrt{2}} \left( \ket{00} + \ket{11} \right)
\end{equation}
The Bell pair \textbf{does not contain} the unknown state. It is simply a resource that Alice and Bob decide to share \textbf{before} teleportation begins. Think of it like preparing the communication channel in advance.

\highspace
\textcolor{Green3}{\faIcon{question-circle} \textbf{Why specifically a Bell pair?}} At this point, it is not clear why we need to use a Bell pair. The answer will become clear in the next section, when we see how the teleportation protocol works. For now, we simply accept that Alice and Bob start with one maximally entangled pair of qubits.

\highspace
\textcolor{Green3}{\faIcon{tools} \textbf{Build the complete state.}} The complete quantum system is simply the tensor product of the unknown state and the Bell pair:
\begin{equation}\label{eq:initial-three-qubit-state}
    \ket{\Psi_1} = \ket{\psi} \otimes \ket{\Phi^+} = \left( \alpha \ket{0} + \beta \ket{1} \right) \otimes \frac{1}{\sqrt{2}} \left( \ket{00} + \ket{11} \right)
\end{equation}
Now, if we distribute the tensor product exactly like ordinary multiplication, there are four products:
\begin{align*}
    \alpha\ket{0} \otimes \ket{00} &= \alpha\ket{000} \\
    \alpha\ket{0} \otimes \ket{11} &= \alpha\ket{011} \\
    \beta\ket{1} \otimes \ket{00} &= \beta\ket{100} \\
    \beta\ket{1} \otimes \ket{11} &= \beta\ket{111}
\end{align*}
Putting it all together, we have the initial three-qubit state:
\begin{equation}\label{eq:initial-three-qubit-state-expanded}
    \ket{\Psi_1} = \frac{1}{\sqrt{2}} \left( \alpha\ket{000} + \alpha\ket{011} + \beta\ket{100} + \beta\ket{111} \right)
\end{equation}
Now we have a complete description of the three-qubit system, and we are ready to start the teleportation protocol.
